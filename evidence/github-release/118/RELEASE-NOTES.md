# 验链 CodeFix 0.3.5-dev｜Windows x64 开发预发行

首次使用请先下载 `FIRST-RUN-GUIDE.txt`，再运行 `CodeFix-Setup-0.3.5-dev-x64.exe`。MD版说明、SHA256SUMS和BUILD.json也在附件中。

## 本版更新

- 证据驱动四角色协作与有界回流，候选隔离测试和干净最终复验。
- 实验对照默认显示最新累计记录，可切原批次并追溯原运行、补跑和逐题证据。
- 明确“单Agent·有界迭代基线”，并非一次简单模型调用；多Agent为四角色证据协作。
- 最新尚未通过题目与历史移交包分开，费用显示已知估算与待核对预留。
- 补充首次安装、配置、费用、运行、结果解释和常见问题说明。

## 第一次使用需要准备

自己的模型Base URL、API Key、精确模型ID，以及管理员发放的云端HTTPS执行地址和个人访问码。两种密钥用途不同；普通用户使用现成云服务，无需在本机安装Python或Docker。模型测试和修复可能收费，请先核对自己的额度、价格与预算。

安装包不带开发者账号、访问码、183条历史任务或私有数据库。新电脑实验页为空并不表示安装失败，附件提供只读图表和CSV/JSON供查看；不会向新用户本机伪造成功记录。当前没有一般源码/仓库上传、自动更新、真人接单关闭或账单自动核销功能。

## 研究结果如何解读

两组各自独立运行相同40题。原批次单Agent38/40、多Agent37/40；三次关联恢复后多Agent累计40/40。累计消耗包括补跑，版本和资源上限有变化，不作为同条件首试因果提升结论。最新尚未通过为单2/40、多0/40；历史移交包2/3份单列，人工实际介入率未记录。

多Agent已知费用估算0.343609元，另0.084076元预算预留待核对；预留不是确认扣费。该数据是开发者的历史研究记录，不是新用户的账单或默认支出。
