## 如何运行

在仓库根目录使用Python3.14；C执行器会检查版本。先安装锁定依赖，再启动本机服务：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m app.cli doctor
.\.venv\Scripts\python.exe -m app.cli validate-config
.\.venv\Scripts\python.exe -m app.cli serve --port 8000
```

打开[本机页面](http://127.0.0.1:8000/)。可信闰年baseline预期3通过1失败，属于缺陷复现，final未运行，不代表模型已经修复。服务仅供本机；API字段和写操作令牌规则以接口规范为准。
