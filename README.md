## 运行与测试

仓库根目录、Python3.14：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m app.cli doctor
.\.venv\Scripts\python.exe -m app.cli serve --port 8000
```

打开[本机任务页面](http://127.0.0.1:8000/)，可信闰年baseline预期3通过1失败、final未运行。这是缺陷复现，不是Agent修复。完整CLI/HTTP/环境变量/模型与Docker前置看[项目运行指南](docs/00_项目导航/项目运行指南.md)。

```powershell
.\.venv\Scripts\python.exe -B -X utf8 -m pytest -q
node --test tests/ui_prototype.test.cjs
```
