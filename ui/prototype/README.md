来源为[UI提交43c333c5a79dccb5204a77f060da45c5c0f2763a](https://github.com/Z1HHAN/Code-Fix/blob/43c333c5a79dccb5204a77f060da45c5c0f2763a/index.html)。本目录仅迁移该提交的index.html并修订演示交互，没有导入原分支的Python脚本、README或运行历史。

**这是独立离线原型，不是运行平台。** 模拟标记始终显示。下拉框切换人工编写的状态快照，允许直接查看不同画面，不代表真实事件流转、实际修复成功或控制规则已生效。demo编号、代码版本、测试数字、Decision、差异和日志均不计运行证据。重新打开或刷新页面会丢弃内存演示状态，不会重跑或收费，因为本页没有任何模型、执行器或后端调用。

打开方式：直接双击本目录[index.html](index.html)，用近期版本Edge或Chrome查看。也可在仓库根目录启动仅供本机查看的静态服务：

```powershell
python -m http.server 8000 --bind 127.0.0.1 --directory ui/prototype
```

然后打开 http://127.0.0.1:8000 。无需安装前端依赖、配置模型API或填写密钥。本页不读取环境变量，也不读写项目代码。
