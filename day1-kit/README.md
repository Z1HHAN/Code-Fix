# Day 1 闰年任务交接包

这是根据两份手册准备的输入材料，不是已实现的修复平台，也不是已运行的证据。
保留 scope.md 作为项目范围依据。本包供 A 发给 B、C，文件无需从外部下载。

## 给 B

接入 configs/task.json，读取 prompts/ 下两份提示词并替换占位内容。
实现流程、模型调用、受限修改、测试执行、日志和停止控制。详细数据约定见“接口说明.md”。
为每轮保存提示词实际输入与原始模型回复，注意避免记录密钥。
运行时复制 code/、tests/ 到 runs/<run_id>/work/，所有测试在 work/ 执行。
只允许修改 work/code/leap_year.py；原始文件和测试保持不变。
本包没有参考答案、保留验收测试和 API 密钥。
模型可以读取当前开发测试失败输出；独立保留测试由 C 另行管理。
模型输入白名单仅包括任务、代码、开发测试输出及定位结论，不要把队长记录表等整个目录都送给模型。

## 给 C

在独立任务副本创建虚拟环境并安装 pytest。进入该副本根目录执行：
python -m pytest tests/ -v

原始版本预期3 passed、1 failed，失败项是1900年。
另建参考验证副本，依据正确闰年规则验证4 passed；不要把参考版本覆盖回原始任务。
参考验证和模型修复分别记录，不得混算。
测试的四个断言来自手册；只调整加载代码方式，避免 code 与标准库同名导致导入问题。
与 B 对齐 ToolRun，并在晚间从原始坏代码的干净副本复核模型生成的修改。

## 给 A

使用“队长今日执行与台账.md”，代替 D 画草图、按说明复跑，代替 E 登记交付与验收结论。
目录中的待执行状态不能当作已完成。测试预期尚未在本机执行验证。
