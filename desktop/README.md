# 验链 Windows 个人桌面应用（开发版）

GitHub Actions → **Build Windows desktop app** → Run workflow → main。成功后下载`windows-desktop-<commit>`，保留3天；包含安装版`CodeFix-Setup-*.exe`、免安装版`CodeFix-Portable-*.exe`、SHA256SUMS、准确构建身份和首次启动截图。二选一使用，不需要另装Python或Docker。尚未签名，构建成功不等于老师电脑的真实验收通过。

安装版提供安装位置、开始菜单/桌面快捷方式和卸载入口，适合老师长期使用；免安装版双击运行，适合临时核验，首次解包可能稍慢。功能相同，无需同时安装。两者都会在当前电脑的应用数据目录保存加密配置；免安装不代表密钥随exe移动，换电脑需要重新填写。

首次打开填写自己的兼容Chat Completions接口的API Base URL、API Key、模型ID、输出上限与参数名，以及云端执行地址/个人访问码。没有预置团队账号。密钥使用Electron safeStorage（Windows当前用户加密）保存，不回显、不写入报告；安装包不带个人配置。更新保留用户数据，换电脑请重新配置。顶部菜单“应用 → 模型与云端连接设置”可修改；正在运行的任务结束前拒绝重启后端。

模型地址使用HTTPS，填写服务商文档中的兼容接口根路径，例如`https://你的服务商/v1`；应用追加`/chat/completions`。自填模型的temperature/top_p尚未核实能力，保持禁用；角色任务指令和输出长度在工作台校验保存后可用。保存、自动检查、刷新和历史回放不生成模型内容。主动点击“测试模型调用”或启动修复才可能收费；测试最多一次请求、30秒、128输出token，不依赖Docker。

金额预算可选，推荐在设置页读取官方价格目录，按API地址、精确型号、地域和模式选择，预览差异后确认并保存。首批包括千问平台qwen-plus、qwen3.5-plus、qwen-max与deepseek-v4.1-flash-1017，以及单独匹配的百炼目录；支持JSON/CSV导入其他服务商价格，每个登记模型分别计价。填写人民币/美元每日额度；旧美元设置兼容保留。价格按Token估算，不是平台余额或账单。关闭时费用显示未知，仍保留任务轮次、调用次数、输出长度和总时限；用量未知或请求失败仍阻止自动继续，不能靠切换配置绕过。任务数据及账本保存在当前用户的应用数据目录，不写入安装目录。

## 正常使用：公网HTTPS，用户无需SSH

填好执行地址与访问码后自动验证鉴权和真实隔离探针，已有配置打开及保存时再次检查。失败留在设置页逐项显示原因；后端启动后还检查/api/v3/health。普通用户无需安装Docker或建立SSH隧道。模型测试与任务共用账本，存在未知用量时显示原因，不自动重复请求。

“读取模型列表”只请求/models，不生成内容；服务商不支持列表时可手填ID。默认模型之外可登记其他模型，合计最多12个，进入工作台分别绑定角色。HTTPS支持非443的Web端口，仍拒绝携带用户名/密码/查询参数的地址；本轮不提供本机HTTP模型代理。

维护者在云安全组允许入站TCP80/443后，在服务器运行：

```bash
bash /opt/codefix/scripts/enable_execution_https.sh 8.148.85.237 --agree-tos
```

先将该脚本上传至对应位置。它安装Nginx，使用已导入Python镜像安装Certbot，申请IP证书、反代本机8780并配置每12小时续期。需要软件源和证书服务可达；参数明确接受证书订阅协议，不读取访问码或模型密钥。脚本完成须看到HTTPS ready；A于2026-11-11回传截图已显示HTTPS ready及续期定时器启用；应用任务隔离探针亦通过，个人真实修复闭环仍待新任务核验。公网只开放80/443，8780保持本机监听。IP证书和Certbot要求依据[官方说明](https://letsencrypt.org/2026/03/11/shorter-certs-certbot.html)。

## 维护者可选：SSH隧道临时联调

在使用应用的Windows电脑上打开PowerShell，执行并保持窗口连接：

```powershell
ssh -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -L 127.0.0.1:17880:127.0.0.1:8780 root@8.148.85.237
```

使用服务器的SSH认证登录，不在应用中保存SSH密码。应用勾选SSH隧道，执行地址填`http://127.0.0.1:17880`，访问码填管理员发放的新码；它不是模型API Key。服务端8780保持仅监听127.0.0.1，不需要向公网开放。这只是维护者临时联调选项；普通使用者走HTTPS，不分发root凭据。

## 本地开发

Python3.14下运行`python scripts/prepare_desktop.py --python-source <完整Windows Python安装目录>`，使用复制后的`desktop/build/python/python.exe -I -m pip install -r requirements-lock.txt`安装依赖。`cd desktop`后`npm ci`、`npm start`；`npm run dist`生成两个exe。构建目录、node_modules、个人凭据与任务日志不入Git。Windows Actions额外检查实际捆绑Python的后端启动和配置保存、已打包Electron首次启动；这些检查均不调用模型或远程Docker。
