## 内部调用契约

```python
from app.runner import prepare_fixture, code_version, run_tests

work = prepare_fixture('leap_original', fresh_destination)
version = code_version(work, ('code/leap_year.py',))
result = run_tests(
    run_id=run_id, task_id=task_id, workspace=work,
    test_profile='leap_original', timeout_seconds=10,
    code_version=version, artifact_dir=artifact_dir,
    phase='development', execution_mode='reviewed_fixture',
)
```

`prepare_fixture`只创建新目录；目录已存在则拒绝。C会再次检查**整个工作副本**与登记哈希一致，包括源码、测试和辅助文件。测试过程使用另一份call级副本，运行前后均检查字节。

`code_version_scheme=sha256-canonical-files-v1`：对明确列出的源码逐文件SHA256，将`{相对路径:完整文件SHA256}`按键排序、UTF-8紧凑JSON后再取完整SHA256，输出`sha256:`加64位。B/C用同一函数；旧的16位版本保留原义，不补造为新版本。测试套件版本独立计算。

`ToolResult.stdout_path/stderr_path/junit_path/structured_path/result_path`均相对于调用者提供的**artifact_dir**，不是仓库或run目录；先拼接artifact_dir再读文件。JUnit不存在时路径为null并有原因；调用拒绝执行时code_version可能为null，requested_code_version保留请求值。

模型上下文只接受明确提供的代码和当前development证据。证据项目为`evidence_id/phase/code_version/summary`；知识项目为`citation_id/knowledge_id/source_path/excerpt`。输出的evidence_ids与knowledge_citations须引用当前输入，后者使用citation_id。返回定位结论前也检查允许路径。上下文组装者是可信控制程序，模型不能自行提供评测目录或密钥路径。

模拟总尝试数2、单次最多1次，定位/修复共享；失败尝试也计数。组件支持显式有限mock传输重试，格式或权限错误不重试。这些是**模拟夹具限制**，不是A已批准的真实费用、请求时限或每日账本。SDK兼容适配离线检查显式timeout与max_retries=0，未启用网络；参考[官方Python SDK文档](https://developers.openai.com/api/reference/python)。
