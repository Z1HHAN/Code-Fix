# 演示流程与回放说明

当前可真实展示可信闰年baseline与公开任务阻断；真实模型修复/独立fixed/对照尚未验收。A讲述、B操作、C核对commit/run_id/证据。官方时长与回放许可待确认。

## 当前可用演示

1. 按[运行指南](../00_项目导航/项目运行指南.md)启动本地服务，选择可信闰年baseline并创建/启动。
2. 展示实际run_id、1900年失败与3过1败，说明这是复现缺陷，final未运行。
3. 刷新同一任务，只查询原run；下载报告/证据ZIP，对照JUnit与哈希。
4. 打开已有公开blocked记录，解释40题导入不等于执行或修好，无资格不在宿主跑。
5. 展示[台账](../04_开发与任务管理/当前开发任务台账.md)中组件完成、真实验证待做与明确阻塞，说明B/C如何回传证据。

可用历史真实来源见[素材索引](版本与演示素材索引.md)。现场复跑只在已有允许的可信范围；原本未获授权的公开/模型执行仍需前置条件。本次文档整理没有重新演示或生成新运行成绩。

## 待真实链完成后的约5分钟脚本

30秒场景/配置 → 90秒真实修复与开发/final → 45秒同任务fixed对照 → 60秒真实失败/停止与移交 → 45秒结果/成本/边界 → 30秒切换余量。没有对应真实run的段落保持待准备；不得人工补修后算自动成功。

每个画面标现场、历史真实回放或明确模拟，故障注入另标且不计模型成绩。冻结平台/任务/模型/提示词/套件版本，至少两次完整彩排；网络故障备用已归档真实记录。录屏文件名可用实际日期，不重命名旧视频伪装新版本运行。
