## 操作

仓库根目录，已安装Python和Node的环境：

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest tests/ -q
node --test tests/ui_prototype.test.cjs
python -m app.cli validate-config
python -m app.cli decision-fixtures
python -m app.cli run-baseline
python C_Day1_20261030/scripts/verify_delivery.py
```

run-baseline仅执行已审阅的人工闰年基线，预期3通过1失败；该命令不会调用模型，独立验收仍未运行。默认pytest只收集tests/组件检查；C包和day1-kit含故意错误的基线，需要明确指定路径运行。

UI启动见[原型说明](../ui/prototype/README.md)。独立页面的演示编号、轮次和报告均为模拟，不是实验成绩。
