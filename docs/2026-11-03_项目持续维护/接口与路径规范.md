## V3当前服务

CLI与HTTP共用TaskService/RunStore。任务输入只接受description、project、mode、max_rounds、max_calls、total_seconds；mode仅baseline/repair；max_rounds 1—3、max_calls 1—30、total_seconds 1—1800。未知字段拒绝，不接受任意Shell、宿主路径或密钥。当前没有fixed入口。

HTTP健康/项目/任务/事件/报告/产物/ZIP与步骤边界control路由见下方唯一HTTP表；写请求需X-Codefix-Token且服务仅供本机。任务可能created/running/paused/blocked/stopped/failed/success，按实际服务返回解释；旧RunSummary草案不能据此批量改原记录。

## HTTP接口


| 方法 | 地址 | 行为 |
| --- | --- | --- |
| GET | `/api/v3/session` | 本机页面取得写操作令牌 |
| GET | `/api/v3/health` | 配置与阻碍；不会把配置存在当成隔离已验证 |
| GET | `/api/v3/projects` | 41个登记题目的来源、预登记测试数、路径、隔离与准入阻碍 |
| POST | `/api/v3/tasks` | 验证并保存任务；可用Idempotency-Key防重复创建 |
| GET | `/api/v3/tasks` | 最近100个任务 |
| GET | `/api/v3/tasks/{run_id}` | 持久化状态与结果 |
| POST | `/api/v3/tasks/{run_id}/start` | 原子抢占，后台执行；重复返回409 |
| POST | `/api/v3/tasks/{run_id}/control` | `{"action":"pause"}`或stop；步骤边界生效 |
| GET | `/api/v3/tasks/{run_id}/events` | 按顺序查询事件；可选after_sequence非负整数，仅返回sequence更大的事件，默认0兼容旧数组 |
| GET | `/api/v3/tasks/{run_id}/report` | 下载JSON运行报告 |
| GET | `/api/v3/tasks/{run_id}/artifact?path=...` | 受限读取本run产物，拒绝越界和链接 |
| GET | `/api/v3/tasks/{run_id}/bundle` | 终态完整ZIP及SHA256清单，最多64MiB |

任务字段：description、project（leap及目录中40个qb-*标识，如qb-quicksort）、mode（baseline/repair）、max_rounds（1—3）、max_calls（1—30，模型调用）、total_seconds（1—1800）。未知字段拒绝。模型默认输出上限2048token、输入保守上限16000token；长日志仅提供当前开发片段。每个新候选都计轮次，不把失败候选计数清零。

写接口需要会话返回的`X-Codefix-Token`。服务拒绝跨站来源与不支持Host，只用于本机；没有远程账号管理/多用户身份认证。OpenAPI文档在[本机/docs](http://127.0.0.1:8000/docs)，写操作仍需提供令牌；建议使用页面或CLI操作。

## 阶段A实装扩展与后续边界

事件新增step_started/step_completed、decision及handoff_created，旧任务不补造Trace；步骤含step_id、parent_step_id、node_id、round、phase。decision的action/effective_action为实际采用动作，program_decision保留规则、model_advice保留建议，override_reason解释不一致；绑定测试evidence_id、代码/测试版本、规则、调用/费用/上限快照。test_completed通过evidence_id及evidence_path关联原始工具产物。代码或测试版本不一致时该证据被拒绝，不进入Agent。

repair所有非成功终态返回handling_status=pending_human、handoff_path=handoff.json；运行状态枚举不变，表示自动流转已停，accepted_by为空。移交内容可由既有artifact?path=handoff.json或bundle下载，不新增人工签收或自动恢复API。产物包含最终候选路径（未生成则null）、版本、证据、消耗、上限、原因与建议。

每run的trace/configuration.json、trace/steps/*.json和trace/decisions/*.json以不覆盖方式保存；原始测试仍保留在baseline/development-N/final-check等原路径，未迁移任何执行路径。

baseline/repair输入字段保持兼容，fixed/dynamic请求参数、高级配置草稿/能力查询API及可点击面板仍在后续阶段；不能把目标设计当现有接口。事件增量游标已可供面板后续使用。模型档案仅服务端配置，不接收页面传入的密钥、任意地址或命令，详见运行指南。
