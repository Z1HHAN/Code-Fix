## V3当前服务

CLI与HTTP共用TaskService/RunStore。任务输入只接受description、project、mode、max_rounds、max_calls、total_seconds；mode仅baseline/repair；max_rounds 1—3、max_calls 1—30、total_seconds 1—1800。未知字段拒绝，不接受任意Shell、宿主路径或密钥。当前没有fixed入口。

HTTP健康/项目/任务/事件/报告/产物/ZIP与步骤边界control路由见下方唯一HTTP表；写请求需X-Codefix-Token且服务仅供本机。任务可能created/running/paused/blocked/stopped/failed/success/interrupted，按实际服务返回解释；旧RunSummary草案不能据此批量改原记录。

## HTTP接口


| 方法 | 地址 | 行为 |
| --- | --- | --- |
| GET | `/`、`/assets/{path}` | 页面和静态资源；不是执行入口 |
| GET | `/api/v3/session` | 本机页面取得写操作令牌 |
| GET | `/api/v3/health` | 配置与阻碍；不会把配置存在当成隔离已验证 |
| GET | `/api/v3/budget` | 本地CNY双账号累计额度/项目估算余额/3元提醒/未知费用阻断；不发平台请求，不返回密钥 |
| GET | `/api/v3/projects` | 41个登记题目的来源、预登记测试数、路径、隔离与准入阻碍 |
| POST | `/api/v3/tasks` | 验证并保存任务；可用Idempotency-Key防重复创建 |
| GET | `/api/v3/tasks` | 最近100个任务 |
| GET | `/api/v3/tasks/{run_id}` | 持久化状态与结果 |
| POST | `/api/v3/tasks/{run_id}/start` | 原子抢占，后台执行；重复返回409 |
| POST | `/api/v3/tasks/{run_id}/control` | `{"action":"pause"}`或stop；步骤边界生效 |
| GET | `/api/v3/tasks/{run_id}/events` | 按顺序查询事件；可选after_sequence非负整数，仅返回sequence更大的事件，默认0兼容旧数组 |

| GET | `/api/v3/tasks/{run_id}/artifact?path=...` | 受限读取本run产物，拒绝越界和链接 |
| GET | `/api/v3/tasks/{run_id}/bundle` | 终态完整ZIP及SHA256清单，最多64MiB |

写接口需要会话返回的`X-Codefix-Token`。服务拒绝跨站来源与不支持Host，只用于本机；没有远程账号管理/多用户身份认证。OpenAPI文档在[本机/docs](http://127.0.0.1:8000/docs)，写操作仍需提供令牌；建议使用页面或CLI操作。

## 运行时审查修复接口补充（024）

- `GET /api/v3/session`：`version`改为实际服务发布值`0.3.0-dev`；新增`requirements_baseline=V3.0`，OpenAPI使用同一服务版本来源。
