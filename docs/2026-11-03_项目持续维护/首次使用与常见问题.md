# 验链 CodeFix 首次使用说明与操作提示

适用版本：0.3.5-dev，Windows x64开发预发行版。普通使用者阅读本文件即可开始配置，无需先阅读研究报告或运行开发命令。

## 1. 先准备四项信息

| 信息 | 从哪里取得 | 用途 |
| --- | --- | --- |
| 模型 API Base URL | 你的模型服务商兼容 Chat Completions 接口文档 | 模型接口根地址，不是聊天网页或模型广场地址 |
| 模型 API Key 与精确模型ID | 你的服务商控制台 | 鉴权、选择具体模型；需要有可用额度 |
| 云端执行服务 HTTPS 地址 | 平台管理员 | 连接已部署的隔离测试服务 |
| 个人执行访问码 | 平台管理员单独发放 | 授权云端执行；它不是模型 API Key |

缺少模型账号或云端地址/访问码时，请先取得对应信息。安装包不内置开发者的密钥、公共访问码或代付额度，也不会自动部署云服务器。使用现成云服务的普通用户，无需在自己的电脑安装Python或Docker；维护者部署服务另见仓库部署说明。

## 2. 下载、校验与安装

1. 从本仓库的 `v0.3.5-dev` 预发行页面下载 `CodeFix-Setup-0.3.5-dev-x64.exe`。
2. 同时下载 `FIRST-RUN-GUIDE.txt` 和 `SHA256SUMS`。前者是本说明的纯文本版，可用记事本打开。
3. 如需核验文件，在下载目录的PowerShell执行：

   ```powershell
   Get-FileHash -Algorithm SHA256 .\CodeFix-Setup-0.3.5-dev-x64.exe
   ```

   将输出与 `SHA256SUMS` 中同名文件的值逐字比较。校验用于确认文件一致性，不等于发布者数字签名；本开发版尚未签名。
4. 双击安装包，按安装向导完成后打开CodeFix。无需再装免安装版，也不要下载GitHub自动附带的Source code压缩包来代替安装程序。
5. 升级前先让任务结束并退出旧窗口，再安装新版。按当前升级路径更新会沿用原用户数据；不要自行删除应用数据目录。

## 3. 首次配置：模型

1. 在个人配置页面填写API Base URL。格式示例为 `https://你的服务商/compatible-mode/v1` 或服务商指定的 `https://你的服务商/v1`；请使用服务商实际文档，不要照抄示例域名。
2. 不要填写官网首页、模型广场、网页聊天地址，也不要在Base URL末尾重复加 `/chat/completions`。
3. 填写自己的API Key，点击“读取模型列表（不生成内容）”。服务商不提供列表时，可手工填写精确模型ID。
4. 模型名称必须与服务商接口一致；网页显示名未必等于接口ID。“其他可用模型”可逐行登记其他ID，合计最多12个，进入工作台后再按角色绑定。
5. 保留适合该模型的输出上限和Token参数名；不要仅因为复杂任务失败就不断提高上限。思考能力必须由已核实的服务商/模型能力支持，不能假设所有模型支持相同参数。
6. 需要真实验证时，先阅读费用提示、确认使用自己的额度，再点击“测试模型调用（可能收费）”。该按钮会发送生成请求；读取模型列表、保存配置和刷新页面不生成模型内容。

模型列表读到并不代表真实生成调用已通过；模型测试通过也不代表云端隔离已经通过，两者分别检查。

## 4. 首次配置：云端隔离

1. 填写管理员提供的执行服务HTTPS地址及个人访问码。
2. 普通用户使用公网HTTPS，不勾选“使用维护者已建立的本机SSH隧道”。隧道选项仅适用于维护者已经建立并保持连接的隧道。
3. 地址和访问码填好后会自动检查鉴权及真实隔离探针，也可以点击“重新检查执行服务与隔离”。
4. 按页面的逐项结果处理问题。需要看到访问码有效、执行服务可达和隔离探针通过；只登录模型账号无法代替这一步。
5. 不要为绕过报错把执行服务随意改成明文公网HTTP；若HTTPS证书或远程Docker有问题，应由管理员修复。

## 5. 价格与预算

1. 使用金额预算前，按实际服务商、API端点、精确型号、地域和模式匹配价格。内置的是已核验价格快照，不是服务商实时余额或完整账单。
2. 可读取百炼／千问平台价格目录，或导入JSON/CSV；先点“校验并预览价格差异”，再点“确认采用预览价格”，最后保存配置。
3. 百炼与其他转发平台不是同一计价主体，不能把某个平台的单价直接套到另一平台；未匹配时应先取得正确价格。
4. 每个模型分别计价，其他角色改用不同模型后也要有对应价格。检查币种以及“每百万Token”等单位，避免相差百万倍。
5. 每日额度由你自己设置；页面默认值不是开发团队替你支付的额度，也不等于一次任务必然花费该金额。
6. 估算按请求usage和价格计算；费用未知不代表免费，预算预留也不是已确认扣费。异常请求可能保留预留，请查看页面原因并核对服务商用量，不要删除账本或换账号绕过限制。
7. 关闭金额预算不等于没有费用，也不取消任务轮次、调用次数、时限及其他守卫。没有价格时不会把费用伪写成零。

## 6. 保存并进入工作台

1. 确认模型、云端访问、隔离检查及预算条件可用。
2. 勾选“我确认使用自己的API额度……”；这是额度授权提示，不是购买套餐或承诺免费。
3. 点击“保存并打开工作台”。保存本身不调用模型、不启动修复；条件不满足时会留在配置页，显示具体原因。
4. 后续修改可从顶部菜单“应用 → 模型与云端连接设置”进入。任务运行中不要修改连接或关闭应用。

若重新打开仍先进入配置页，可核对现有设置后再次“保存并打开工作台”；已保存的密码输入框留空通常表示沿用当前Windows用户的加密配置，不需要把密钥粘贴到聊天或截图里。

## 7. 第一次运行：先完成一道已登记任务

1. 在工作台创建任务，选择一个已登记的Python题目，填写简洁目标，例如“在不修改冻结测试的前提下修复该题”。当前版本没有面向普通用户的任意仓库上传入口。
2. 选择已保存的模型、角色和策略配置，核对轮次、调用数、时限与预算。先使用默认有界配置；默认3轮是最多尝试3轮，成功会提前停止。
3. 创建任务只登记记录，明确点击“启动任务”才执行；启动修复可能调用模型并收费。
4. 查看基线、候选测试、模型调用和最终复验。已登记坏版本的基线断言失败通常是成功复现缺陷，不应单凭“断言失败”认定平台损坏。
5. 候选开发测试通过后仍需干净副本最终复验；只有相应final证据通过才视为修复成功。
6. 任务结束后查看代码差异、每轮测试和报告，可下载证据ZIP。失败或暂停也保留记录，不会为了凑满轮次而继续改动已通过的候选。

模型请求数、角色调用尝试数和修复轮次是不同计数。多Agent并不保证每道题固定调用全部四个角色。

## 8. 正确理解单Agent与多Agent

- **单Agent·有界迭代基线**：修复Agent同样读取工具反馈，在上限内多轮修改，接受隔离测试和最终复验；不是只给模型一个提示、调用一次就结束的简单基线。
- **多Agent·四角色证据协作**：保留修复、检测、模型调度和定位的独立合同、上下文与交接，按错误证据触发分支；工具证据和程序规则决定实际动作。
- 两组可以共用同一个基础模型；“四个Agent”不等于四种模型或四个独立操作系统进程。

## 9. 实验对照区与历史数据

两组是各自独立运行相同题集，不是把40题分给两个组。默认“最新记录（含关联补跑）”可回看原始批次，并保留原运行与补跑证据。

本项目已有历史研究结果为：单Agent有界迭代基线38/40，多Agent原批次37/40，三题关联恢复后累计40/40。累计消耗包含补跑，补跑版本与上限变化，不能仅凭累计差异推断同条件因果提升。

当前“尚未通过题目”为单2/40、多0/40；原批次历史移交包仍为2份、3份。历史7.5%不表示多Agent现在仍有三题没修好。人工实际介入率缺少接单、签收记录，不把它写成0%或7.5%。

**新电脑的实验区为空可能是正常情况。** 安装包不复制开发者的183条任务、私有数据库、API Key或访问码。页面只显示当前用户已有的运行记录，不会伪造成功历史。要查看本次研究成果，可先阅读发行附件中的截图、指标CSV/JSON及仓库证据；要在应用里建立自己的对照，需要完成并关联自己的两组运行，查看或保存清单不会替你自动执行40题。

## 10. 常见问题与处理提示

| 现象 | 优先检查 |
| --- | --- |
| 模型401/403或鉴权失败 | API Key是否属于当前端点、是否有效及有权限；不要把执行访问码当模型Key |
| 模型不存在或列表没有该ID | 使用服务商精确接口ID，检查Base URL；列表不可用时可手填，仍需真实测试 |
| 执行服务401/403 | 管理员提供的执行地址、访问码是否匹配，码是否已撤销 |
| 隔离未就绪 | 展开具体原因；管理员检查远程Docker、测试镜像、权限和服务版本。仅模型登录成功无效 |
| 测试模型通过但修复0次调用 | 查看运行记录的前置条件、基线、预算、权限和停止原因；不要只看模型设置页 |
| 空正文或输出格式错误 | 查看角色具体诊断、模型模式与输出上限；不原样无限重试，不把空输出当成功补丁 |
| 网络超时、未知费用或待核对预留 | 查看是否已发送和预算处理提示；预留不是实际账单，避免手动重复收费重跑 |
| 第一轮就结束 | 可能已成功提前结束，也可能被明确条件阻断；看final和结束原因，不以轮数单独判断 |
| 历史移交比例高但最新通过 | 历史包保留用于追溯，当前尚未通过和实际人工介入分开读取 |
| 新安装没有40题历史对照 | 安装包不分发私人任务数据库；查看附件示例，或执行自己的任务 |
| 换Windows账号/电脑后配置无法解密 | 加密配置绑定本机Windows用户，重新填写自己的配置；不要把旧密文当可移植密钥包 |

提交问题时只提供版本号、脱敏后的错误文字、任务ID和必要截图；不要发送API Key、访问码、SSH密码或未脱敏的配置文件。未公开源码可能被发送给你配置的模型服务商，提交前应确认自己有权使用这些代码。

## 11. 数据、更新与卸载提示

运行记录、账本和加密配置保存在当前Windows用户的应用数据目录（通常为 `%APPDATA%\codefix-desktop`），不保存在安装包里。对数据目录操作前应退出任务并先备份；不要把其中的凭据和数据库提交GitHub。

本版通过下载新安装包并更新来升级，不宣称已实现自动更新、任意样本上传、真人接单关闭、自动测试生成或服务商账单自动核销。自行卸载或清理用户目录前，先确认需要保留的报告、任务和配置。

## 12. 版本与验证边界

本包为Windows x64开发预发行版，尚未数字签名。已进行开发者本机安装、配置、实验视图切换与导出检查；最新源码回归为Python836通过、1项本机符号链接权限跳过，前端及桌面配置86通过。历史Windows Job回收间歇失败记录仍保留，本轮未复现不代表已根治；不代替其他电脑、真实模型服务商或独立验收人的验证。

首次使用按顺序完成：**取得模型与云端信息 → 安装 → 分别检查模型和隔离 → 核对价格/预算 → 保存 → 先运行一道题 → 查看final和证据。**
