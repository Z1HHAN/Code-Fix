## 2. P0：证据可信（必须做）

### RF-01 final_check 逐字节绑定

**改法**（`app/workflow_v3.py:286-291`）：
```python
def final_check(self):
    final_work = self.directory / 'final-work'
    payload = (self.current / self.source).read_bytes()
    apply_candidate(self.base, final_work,
                    [{'path': self.source, 'new_content': payload.decode('utf-8')}],
                    self.directory / 'final-patch', project=self.task['project'])
    (final_work / self.source).write_bytes(payload)
    if code_version(final_work, (self.source,)) != self.version:
        raise IsolationBlocked('最终验收字节与候选版本不一致')
    checked, _ = self.test(final_work, 'final_check', 'final-check')
```

**验收**：
- 新增 `test_final_check_preserves_crlf_candidate`：CRLF 候选 → `passed` 且 `final['code_version'] == code_version(final_work)`；
- 新增 `test_final_check_rejects_version_mismatch`：版本不一致 → `IsolationBlocked`。

**风险**：极低。CRLF 候选此前会被静默改写，现在要么保真要么 blocked。

### RF-05 `_junit_key` 括号感知

```python
def _split_nodeid(nodeid):
    parts, depth, start, i = [], 0, 0, 0
    while i < len(nodeid) - 1:
        if nodeid[i] == '[':
            depth += 1
        elif nodeid[i] == ']':
            depth = max(0, depth - 1)
        elif nodeid[i] == ':' and depth == 0 and nodeid[i + 1] == ':':
            parts.append(nodeid[start:i]); start = i + 2; i += 1
        i += 1
    parts.append(nodeid[start:])
    return parts
```

**验收**：`test_x[a::b]` 与 `test_x[1]` 都得到正确 `(classname, name)`。

## 4. P2：工程化与流程

### RF-08 Split 审计 fail-closed

- `logs_captured=False` → `environment_error`；
- 检测到日志被截断（`docker logs` 首行不是已知起始标记）→ `environment_error`；
- 或改宿主持久化审计流。

**验收**：构造"候选写 2MiB stdout"用例，断言运行被判环境错误而不是通过。

### RF-09 账本粒度与重试

- pending 检查加 `account_id`/`currency` 过滤；
- 新增错误码 `ledger_busy`，workflow 捕获后 `pause`（可重试），`unknown` 仍 `blocked`；
- 记录 reconcile 入口。

**验收**：两个并发任务不再互相 blocked；单账号超额仍被拦。

**风险**：中——改变并发行为与失败码，需 C 复跑全部控制场景。

### RF-10 单容器恶意变体门槛

- 在 Docker 套件里增加"候选延迟退出 + 改写 `/out`"用例；
- 期望：`evidence_channel_tampered` 或 `environment_error`，不得 `passed`。
