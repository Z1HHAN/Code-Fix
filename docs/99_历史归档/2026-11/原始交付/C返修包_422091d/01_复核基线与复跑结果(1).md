## 2. 环境与方法

- 本机沙箱对被审目录只读，无法原地写盘；复核在隔离副本 `D:\deepseek-harness\default-workspace\cx-review\repo` 上进行（robocopy 复制，排除 `.venv/.git/__pycache__`）。
- Python 3.14.10 新建 venv；依赖从本地 `wheelhouse314` 离线解包，版本与 `requirements-lock.txt` 一致；未联网安装、未改动被审仓库。
- **环境 shim（必须披露）**：
  1. 本机沙箱下 `mkdir(mode=0o700)` 产生的目录连创建者都不可读（ACL 拒绝），pytest 的 tmp 目录全部中招；复跑时用只作用于 `_pytest` 的 shim，让 pytest 用普通权限建临时目录。
  2. pytest session 结束时的符号链接清理会因同一 ACL 抛 `PermissionError`，shim 忽略该异常。
  - 两处均不改变被测代码语义，但意味着这是"本机复跑"，不是在 B 机原样复跑。
- Node 测试：本沙箱内 `node --test` 为每个文件 spawn 子进程会触发 `EPERM`（沙箱既有限制），改为 `node tests/xxx.test.cjs` 逐文件进程内运行。
